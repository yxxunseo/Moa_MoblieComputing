## 프로젝트 개요

**모아**는 그룹의 일정을 조율하고 관리하는 데 특화된 Android 기반 모임 일정 관리 앱입니다.  
개인 일정과 그룹 일정을 한곳에서 확인하고, 구성원들의 가능한 시간을 취합하여 최적의 약속 시간을 추천·시각화합니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| **스마트 일정 조율** | 팀원들이 각자 가능한 시간을 선택하면 교집합 시간을 분석·추천 |
| **통합 캘린더** | 개인 일정 + 그룹 확정 일정을 그룹별 색상으로 통합 관리 |
| **외부 캘린더 연동** | Google Calendar / Apple Calendar 연동 지원 |
| **단기 모임 링크** | 앱 설치 없이 웹 링크로 시간 입력 가능 |
| **일정 상태 관리** | 응답 대기 → 조율 중 → 확정됨 → 완료됨 |
| **푸시 알림** | 일정 확정·추가 시 즉각 알림 |

## 앱 구조

```
하단 네비게이션
├── 홈        — 대시보드 (다가오는 일정, 그룹 알림)
├── 캘린더    — 개인 + 그룹 일정 통합 뷰
├── 모임      — 그룹 목록, 생성 / 입장
└── 마이      — 프로필, 외부 캘린더 연동, 설정
```
